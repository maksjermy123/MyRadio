# 📖 Оглавление + 📻 Радио + 📚 Глубже — Telegram Mini App

Христианский канал «От чтения к Преображению» как Telegram Mini App:
- Оглавление всех постов канала по категориям с поиском (в т.ч. по второстепенным тегам)
- Христианское радио (несколько станций, прямой эфир)
- Кнопка «📚 Глубже» под постами — библейские тексты, богословские цитаты, вопрос для размышления
- Проверка подписки на канал перед входом
- Автоматическая индексация новых постов через webhook

---

## Архитектура проекта

```
Telegram-канал (@Chtenie_Preobrazenie)
        │
        │  новый пост с #хэштегом
        ▼
Render (main.py — FastAPI)
        │
        ├── проверяет хэштег → определяет категорию
        ├── скачивает posts.json с GitHub
        ├── добавляет пост → загружает обратно
        ├── запускает AI-анализ (Groq + Cohere + Bible DB)
        ├── сохраняет результат в links.json
        └── добавляет кнопку «Глубже» к посту в канале
        │
        ▼
GitHub (posts.json + links.json — хранилище данных)
        │
        ▼
GitHub Pages (index.html + deeper.html — Mini App)
        │
        ▼
Пользователь открывает Mini App → Оглавление / Радио / Глубже
```

|---|---|

### Обслуживание и переиндексация
| URL | Описание |
|---|---|
| `/reindex_all` | Пересобирает topics и tags всех постов из текста по актуальному HASHTAG_MAP |

| `/remove_button/{post_id}` | Удаляет кнопку с поста канала |
| `/cleanup` | Удаляет кнопки с постов без AI-тегов (#цитата, #продолжение и т.д.) |
| `/debug_last` | Последние 5 постов в индексе |

Если пост не помещается в одно сообщение Telegram:
1. В первом сообщении добавь `#продолжение` и напиши «Продолжение ниже 👇» в конце
2. Второе сообщение начинай с «Продолжение...»

Бот автоматически склеит тексты обоих постов для AI-анализа. Кнопка «Глубже» появится только под вторым сообщением.

## Как работает кнопка «📚 Глубже»

1. Новый пост приходит через webhook
2. Бот индексирует его в `posts.json`
3. Запускается AI-анализ (Groq llama-3.3-70b):
   - Находит библейские тексты которые использует или которые дополняют автора
   - Cohere Rerank ищет релевантные богословские цитаты (порог 0.92 — если нет подходящих, не показывает ничего)
   - Формулирует вопрос для личного размышления
4. Результат сохраняется в `links.json`
5. К посту добавляется кнопка `📚 Глубже` → открывает `deeper.html?post_id=X` как Mini App внутри Telegram

Кнопка **не добавляется** к постам с тегами: `#цитата`, `#анонс`, `#новости`, `#продолжение` (первая часть).

## Первоначальная настройка (с нуля)

### Шаг 1 — Создать бота в Telegram

1. Открой **@BotFather** → `/newbot`
2. Придумай имя и username (должен заканчиваться на `bot`)
3. Сохрани токен вида `1234567890:AAG...`
4. `/mybots` → выбери бота → **Bot Settings → Group Privacy → Disable**
5. Добавь бота администратором в канал (право «Управление сообщениями» обязательно)

### Шаг 2 — Получить API ключи

- **Groq** (бесплатно): [console.groq.com](https://console.groq.com) → API Keys → Create
- **Cohere** (бесплатно): [dashboard.cohere.com](https://dashboard.cohere.com) → API Keys

### Шаг 3 — Создать GitHub Token

1. github.com → аватар → **Settings → Developer settings → Personal access tokens → Tokens (classic)**
2. **Generate new token** → название → срок **No expiration** → галочка ✅ `repo`
3. Сохрани токен `ghp_...` — показывается только один раз!

### Шаг 4 — Задеплоить бэкенд на Render

1. Зайди на **render.com** → **New Web Service**
2. Подключи репозиторий
3. Runtime: **Python 3**, Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
4. Вкладка **Environment** → добавь все переменные из таблицы выше
5. После деплоя скопируй URL вида `myradio-xxxx.onrender.com`

### Шаг 5 — Зарегистрировать webhook

```
https://myradio-xxxx.onrender.com/set_webhook
```
Должен увидеть `"ok": true`.

### Шаг 6 — Настроить кнопку меню бота

В **@BotFather**:
```
/mybots → выбери бота → Bot Settings → Menu Button → Configure menu button
URL:   https://t.me/preoradio_bot/radio
Текст: 📖 Оглавление + Радио
```

## Переиндексация (при изменении кода)

После изменения `HASHTAG_MAP` или структуры постов:

**1. Обновить topics и tags всех постов:**
```
https://myradio-rrsk.onrender.com/reindex_all
```

**2. Запустить AI-анализ по частям** (delay=45 чтобы не превысить лимит Groq):
```
https://myradio-rrsk.onrender.com/analyze_range?from_id=220&to_id=290&delay=45
https://myradio-rrsk.onrender.com/analyze_range?from_id=291&to_id=340&delay=45
https://myradio-rrsk.onrender.com/analyze_range?from_id=341&to_id=370&delay=45
```
Каждую часть запускай после того как предыдущая завершилась (`завершено N/N` в логах Render).

**3. Почистить лишние кнопки:**
```
https://myradio-rrsk.onrender.com/cleanup
```

## Поддержание сервиса

**Render засыпает** на бесплатном тарифе через 15 минут без запросов. Решение — **UptimeRobot**:
- Мониторит `https://myradio-rrsk.onrender.com/` каждые 5 минут

**Groq лимит** — бесплатный тариф: ~6000 токенов в минуту. При анализе постов используй `delay=45`. Лимит сбрасывается каждые 24 часа (в 03:00 по Москве).

**GitHub Token** — без срока истечения. Если скомпрометирован — немедленно удали и создай новый. Никогда не публикуй в открытом коде.

**Логи Render** — при проблемах с индексацией ищи строки:
```
▶ update_id=XXXXX | поля: ['channel_post']
Пост 370 | теги: ['#библия'] | темы: ['📖 Библия и толкование']
Пост 370 — added ✓
✅ Post 370 processed. Related: [...]
✅ Кнопка «Глубже» добавлена к посту 370
```
